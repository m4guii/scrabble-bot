# Scrabble Game With Bot

Project developed for Foundations of Programming course at Instituto Superior Técnico.

## Overview
This is a terminal-based Scrabble game, where you can play against a bot. The game is set to be played in Portuguese, but easily extended to allow different dictionaries. 

## Tools
* Python

## Features 
* Game Logic: Handles tile drawing, word validation, score calculation, and board rendering.
* Optimized Loop: Refactored the vocabulary file parsing and game loop for better performance.

## How to run
`python3 main.py`
